GymRecords v0.6.4 – Asset Consistency Hotfix

Implemented in this hotfix:
- Cardio photo switcher is now interactive (tap the indicator/label or swipe).
- Cardio group card now uses a dedicated cardio visual instead of the legs image.
- Cardio personal-record achievement sheet now shows the GymRecords mascot.
- Exercise image resolution logic now distributes fallback visuals by exercise id/equipment instead of collapsing many exercises into the same image.
- Added diversified abs/core fallback assets to reduce repeated thumbnails.
- Muscle view now uses a cleaner anatomical slide with contain fit, improving female/neural alignment and avoiding displaced highlights.
- Exercise and cardio pagers now support direct toggling via the on-card control.
